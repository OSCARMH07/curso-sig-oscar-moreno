# curso-sig-oscar-moreno

Trabajos del curso Servicios SIG y Sitios Web
(Maestría SIG, UJdeC).

## Cómo se ejecuta

El archivo hospitales_boyaca.geojson puede
abrirse directamente en QGIS.

Los datos se descargan desde el repositorio
oficial del curso mediante el comando:

    python scripts/descargar_boyaca.py --out nivelacion/datos

## De dónde salen los datos

Paquete de datos de Boyacá descargado mediante
el script del profesor, a partir de información
del DANE y la IDE Boyacá.

Repositorio oficial:
https://github.com/epiragauta/servicios_sig_y_websites
